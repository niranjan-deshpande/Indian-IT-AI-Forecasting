# Indian IT and AI: pilot analysis

Pilot research note on the headcount slowdown at India's largest IT services firms (SPAR, Fall 2026).

- **The note:** `docs/index.html` (served with GitHub Pages). The text lives in `note_text.md`; rebuild with `python3 scripts/final/build_note.py`.
- **Number check:** `note_number_check.md` (`python3 scripts/final/note_number_check.py`).
- **Data, tables and figures:** `python3 scripts/final/make_all.py`. See `FINAL_PASS_SUMMARY.md` and `note_inputs.md`.

Downloaded source documents (`data/sources/`) are not included; their URLs are recorded in the data and audit files.
