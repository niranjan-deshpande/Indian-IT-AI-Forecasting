## Computer User Support Specialists

**Both models (collapse):** 1
- 1282a = 1288a: “one user call, chat, or walk-up question answered” / “one problem diagnosed and resolved during a user contact” — Both are one live user contact where the specialist works out and fixes the user's problem and the user confirms or it is logged, so doing one is doing the other.

**Claude only:** 1
- 1283b = 1285b: “one routine system check round (e.g. daily check of servers, printers, network links)” / “one daily system status review” — Both are a start-of-day or scheduled round of checking servers and systems and monitoring data, with results recorded and errors raised as tickets, so the same work would be counted twice.
