# ui_cube: SOURCE
- Accessed 2026-11-10. Repo https://github.com/UiPath/uipath_enterprise_benchmark (main; no LICENSE file found at /LICENSE), tasks in DeterministicBenchmark/deterministic_bench.json; paper arXiv 2511.17131 (v1, 21 Nov 2025). No gating.
- Population: all 226 tasks in deterministic_bench.json (paper: 136 simple widget tasks + 90 complex = 50 copy-paste/business-process + 40 enterprise apps; the repo files list 144 widget-style incl. 8 kanban, 40 copy-paste, 10 business-process, and 8 each Salesforce, Concur, SAP, Workday). Headline numbers in the paper are reported per tier, so I pooled them task-weighted (136 simple, 90 complex). Sample: random.Random(2026).sample(sorted 226 ids, 24); `text` = task question + UX hint.
- Grading method: `state`. A test() oracle checks the app's final state (window.app_state) or the submitted JSON answer, deterministically.
- Description for time estimators: A short task on a web page or replica business app (set a date, pick from a combo box, navigate a table, copy records between pages, look up SAP stock, file a Concur expense); done when the app state or submitted answer matches the goal.
- Human times: only collection-level averages (paper Table 7: avg duration s and steps per task collection, from humans new to the apps), e.g. 3 s (hierarchical navigation) to 267 s (business process); simple 10.7 s, complex 149.2 s. Put in each item's meta. Not per task. Human accuracy 97.9% simple / 61.2% complex.
- Scores: 5 agent configurations, each at 3 resolutions (XGA, 1080p, 4K). Row score = pooled (136*simple + 90*complex)/226 of the 3-resolution average (Table 5). 4K strongly depresses results; 1080p pooled values are in notes. Three rows are the same UiPath scaffold with different planner LLMs.
- Problems: only 5 rows, all Nov 2025 (single snapshot; no exact eval dates; paper date used), derived from tier averages not raw per-task results (not published; ACQUISITION lists UiPath contact), human accuracy on complex tasks only 61% suggests strict/brittle oracles, mixed scaffolds (native CUAs vs UiPath planner+grounder), release date of "Claude Computer Use 4.0" model ambiguous. Task URLs point to a UiPath-hosted IP; tasks run via the repo Docker app. Public full set.
