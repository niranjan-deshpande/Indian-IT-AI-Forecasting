# Spider 2.0-Snow (spider2)
- URLs: https://spider2-sql.github.io/ (leaderboard, saved raw/lb.html and lb.txt), https://github.com/xlang-ai/Spider2 (README; spider2-snow/spider2-snow.jsonl, spider2-lite.jsonl, spider2-dbt jsonl fetched from raw.githubusercontent main). Paper arXiv 2411.07763 (ICLR 2025 Oral). Accessed 2026-11-10. Licence: repo Apache-2.0 per upstream. Commit hash not retrieved.
- Which split: the catalog text ("business question over a large warehouse ... some items are transformation projects") covers the umbrella benchmark; the leaderboard has three separate tracks (Snow 547, Lite 547, DBT 68). I chose Spider 2.0-Snow (547 tasks, all Snowflake, self-contained, most leaderboard rows and the Spider-Agent baselines). DBT (project-level transformation) is not sampled; Lite shares most questions. If the project wants DBT items, sample from raw/spider2-dbt.jsonl (67 lines downloaded; leaderboard says 68). Sample: random.Random(2026).sample(sorted(instance_id), 24).
- Item text = db_id + question; an external-knowledge document name is added when present (contents not fetched).
- Grading method: `exact_answer` (the output CSV result table is compared with gold answer tables; programmatic, not tests/LLM).
- Description for time estimators: Given a question from a business user about a large company data warehouse (Snowflake, often hundreds of tables and 1,000+ columns) and any supplied documentation, explore the schema and write SQL that answers it; done when the returned result table matches the correct answer.
- Published human times: none.
- Problems: leaderboard has no dates and no model-only column: rows are "method + model". Baseline rows use the official Spider-Agent scaffold (comparable across time); third-party systems (marked [system: ...] in model) score far higher with the same model and are not comparable. eval_date is blank everywhere; release dates from provider announcements, some blank. Scores can shift as the evaluation suite is fixed. Top scores are about 96%, nearing saturation. Gold results are public for self-eval; contamination possible. Single Snow track only.
