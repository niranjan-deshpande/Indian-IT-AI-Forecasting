# TheAgentCompany (theagentcompany)
- URLs: https://github.com/TheAgentCompany/TheAgentCompany (commit 98b68ef, 2025-11-17; task.md, checkpoints.md, scenarios.json per task via raw.githubusercontent), https://github.com/TheAgentCompany/experiments, leaderboard https://the-agent-company.com/#/leaderboard (data embedded in the site JS bundle, saved raw/main.js and raw/leaderboard.json). Paper arXiv 2412.14161. Accessed 2026-11-10. Licence: MIT.
- Population: all 175 task directories in workspaces/tasks (leaderboard says "Total of 175"; includes a template task named `example`, which the leaderboard also counts). Sample: random.Random(2026).sample(sorted(task_dir_names), 24).
- Item text = task.md instruction (leading to 190 words) + list of colleagues reachable by chat + the checkpoint descriptions (what must be true when done). Simulated-colleague hidden strategy hints were left out.
- Grading method: `state` (per-task evaluator.py checks final files, repo/tracker state and chat messages; some checkpoints use an LLM to judge message content). Leaderboard headline "% Resolved" = all checkpoints pass; "score" gives partial credit (kept in notes).
- Description for time estimators: A work task inside a simulated software company (code host, project tracker, file share, team chat with colleagues; roles such as developer, PM, HR, admin, finance, data scientist): follow a short written instruction that may require chatting with colleagues, then produce the final files, records or messages; done when every listed checkpoint on the end state is met.
- Published human times: none in the benchmark (checkpoint points only, in meta). arXiv 2510.22780 (48 timed workers, TAC-style tasks) is a separate calibration source.
- Problems: scores are for agent+model combos on mixed scaffolds (OpenHands baseline; OpenHands-Versa, MUSE, TTE-MatrixAgent are different frameworks, the latter two with other helper models). 17 leaderboard rows, newest 2025-11-10; none after. Leaderboard dates are submission dates, possibly later than model release. Claude 3.7 Sonnet has two scaffolds; best kept (OpenHands 26.29% noted). Some release dates are approximate (see notes). Full 175-task set is public; resolved rate saturates near 43%, not saturated.
