# SWE-Lancer, IC SWE Diamond (swe_lancer)
- URLs: https://github.com/openai/preparedness/tree/main/project/swelancer (all_swelancer_tasks.csv, README; fetched raw.githubusercontent main, access 2026-11-10; commit hash not retrieved because the GitHub API rate limit was hit). Paper arXiv 2502.12115 (v4, 2025-05-29; saved raw/paper.html). System cards: GPT-4.5 (cdn.openai.com/gpt-4-5-system-card-2272025.pdf), GPT-5 (cdn.openai.com/gpt-5-system-card.pdf). Licence: repo MIT-style per OpenAI; task text is from public Expensify GitHub issues (Expensify/App). No gated data.
- Population: the CSV's 198 rows with variant=ic_swe (set=diamond). The repo README says the public repo has 198 of the paper's 237 Diamond IC tasks (as of 2025-07-17). Sample: random.Random(2026).sample(sorted(question_id), 24). SWE Manager tasks (265) excluded.
- Item text = issue title + reproduction text with Expensify template header, links and images stripped, plus repo name; max ~190 words. The `proposals` column was not used.
- Grading method: `tests` (engineer-written end-to-end Playwright browser tests, hidden from the model, must pass).
- Description for time estimators: Fix a real bug or small feature in a commercial React Native/TypeScript expense-management app (Expensify), given the issue report and the repository; done when end-to-end browser tests for the corrected behaviour pass.
- Published human times: none per item. meta.price_usd is the freelance bounty ($250 to $32,000 range overall) as a size proxy; paper Table 8 gives mean "resolution time" (25 days for IC Diamond, apparently calendar days of the open issue, not effort).
- Problems: scores before July 2025 (paper, GPT-4.5 card) are on the original 237-task set; GPT-5 card scores are on the 198-task public set (avg of 3 runs); n_items column marks which. Post-GPT-5 models not collected (system-card figures only; no official leaderboard; launch-post values for newer models, e.g. Claude, not found). System-card values are read off bar-chart labels (rounded to whole percent) in the PDFs. Several rows are products (deep research, ChatGPT agent). Scaffold differs (OpenAI SimpleAgent vs internal). Public items are a subset of the full 764-IC set plus held-out.
