# officeval: SOURCE
- Accessed 2026-11-10. Dataset https://huggingface.co/datasets/baidu-frontier-research/OmegaUse-OfficeVal (not gated, Apache-2.0; used data-studio/train.jsonl, English), code https://github.com/baidu-frontier-research/OmegaUse-OfficeVal (verifiers), paper arXiv 2607.27155 (v2, 18 Aug 2026, CC BY 4.0), site https://omegause-officeval.github.io/. Dataset sha 8e19c575 (lastModified 2026-09-03). Input files not downloaded (names taken from metadata).
- Population: all 100 tasks (Word 37, PowerPoint 39, Excel 19, PDF 4, cross-file 1). Headline = mean over all 100 tasks of the normalized task score. Sample: random.Random(2026).sample(sorted 100 ids, 24).
- Grading method: `tests`. Deterministic code verifiers on the output file(s): all usability checks must pass (else 0), then weighted rubric items (+1/+3/+5 required, -1/-3/-5 for collateral damage), clipped at 0, divided by max positive. Partial credit.
- Description for time estimators: A real office request with one or more Word, Excel, PowerPoint or PDF files (restructure or reformat a report, fix a spreadsheet, extract data into a table, annotate a document); done when the edited files meet an expert checklist without breaking the rest of the files.
- Human times: `human_labor_time` (minutes) per task, in meta. Measured by recruited annotators doing the task without LLM help; mean of the two shortest valid completion times (at least 2 annotators, third added if they differ). Mean 139 min (2.32 h), median 2.03 h, max 8.35 h. Also `task_price_proxy` (yuan) in meta.
- Scores: 5 LLMs in one in-house scaffold (shell, file ops, LibreOffice), 4 h timeout per task. Human baseline (best of annotators) scores 0.2779; not included as a row.
- Problems: score is a mean partial-credit score, NOT a fraction solved; the horizon fit assumes solved/unsolved, so binarize (e.g. full score or >= human score) only if per-task results are obtained (not published; ACQUISITION plan is to run models ourselves). Only 5 models, all open-weight/China-lab, from one snapshot (Apr-Jun 2026 releases, eval ~Jul 2026), no time trend. Exact eval dates and some release dates are not stated. Task instructions partly in translated English; many inputs are Chinese documents. Public 100-task set, full benchmark (not a subset).
