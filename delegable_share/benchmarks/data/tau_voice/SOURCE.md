# tau_voice (tau-Voice, voice-v1 English leaderboard frame)
- URLs: https://github.com/sierra-research/tau2-bench (README "Released benchmarks" table; data/tau2/benchmarks/voice-v1.json, voice.json); leaderboard JSONs web/leaderboard/public/submissions/*/submission.json (modality voice) and 2.0 packages benchmark-submission.json.
- Access date: 2026-11-09. Licence: MIT (sierra-research/tau2-bench). Repo commit 033bf082f48e4a3c6a1256208e93cf2ce9c3bb6f (main, 2026-11-04). Raw files in tau_retail_airline/raw (tasks, split files, policies, manifest.json, subs/ = all leaderboard submission JSONs) and the benchmark's own raw/ folder.
- Same tasks as text? Yes. voice-v1 = English airline 50 + retail 114 + telecom 114 = 278 calls, the same task ids as the text domains (airline base 50, retail base 114, telecom base 114); only the medium (full-duplex speech, TTS caller) differs. A later frame, voice-v2 (tau-i18n), uses 50 tasks per domain x 6 languages = 900 calls (retail_50, telecom_50 are smaller subsets).
- Population sampled: voice-v1 pooled 278 tasks ("airline:<id>", "retail:<id>", "telecom:<id>"), random.Random(2026).sample(sorted ids, 24). Item text is the text-task content, framed as a live phone call; the voice-specific caller voices/noise are not part of the item text. Same task items appear under the text benchmarks with different item ids.
- Headline = pass^1 per domain; scores.csv pools them with task-count weights (50/114/114). Standard (non-custom) entries preferred; custom user-simulator variants listed in notes. One model (gemini-3.8-live-extended-thinking) has only a voice-v2 English-cell score on a 150-task frame (50/50/50), flagged in score_kind/notes: not comparable with the 278-call rows. v2 packages for other models (gpt-live-1, grok-voice-think-fast-2.0, Ava Zero, phonic-1) were not used because a v1 row exists.
- Grading method: state (same DB/environment assertion checks as text).
- Time-estimator description: A phone call from a customer to a retail store, airline or mobile carrier with a request to fix or change something (exchange/return/cancel an order, change a booking, fix a phone problem); the agent must verify the customer, follow the written policy by voice, and make the right system changes; done when the records are right.
- Human times: none; call durations exist in S3 trajectories (s3://sierra-tau-bench-public/, access not tested).
- Problems:
  - Evaluation conditions vary: caller simulator v1.0 vs gpt-5.5, tau2 versions 1.0.0 / 1.0.1 / 2.0.0 and some unpinned commits; many entries custom or vendor-run. Voice release dates blank for Pine Voice 1.0, Salesforce Launa and gemini-3.8-live (not in source files).
  - Rapid growth: 0.25 (2025-12) to 0.86 (2026-10). Telecom/retail unequal difficulty, so pooled weights matter.
  - Retail frame in voice-v2 uses 50 tasks, not 114.
