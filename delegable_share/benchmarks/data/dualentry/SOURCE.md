# dualentry (DualEntry "Accounting AI Benchmark" / DualBench100) - source notes

- Accessed 2026-11-10. Pages: https://www.dualentry.com/benchmark (raw/benchmark.html), https://www.dualentry.com/benchmarks, blog posts (March 2026 round: .../new-openai-gpt-5-4-real-accounting-workflow-test; .../ai-still-fails-one-third-of-real-accounting-tasks),
  methodology paper PDF "DualBench100" (raw/dualbench100.pdf, methods only, no results). Licence: no data licence stated (web content, copyright DualEntry); only the published example table and leaderboard numbers used.
- Population: 101 synthetic cases, 8 categories (13/13/13/12/13/12/12/13: classification, journal entries, AP, AR, bank rec, financial reporting, month-end close, knowledge MCQ); 37 easy/36 medium/28 hard.
  **The 101 cases are NOT public** (no dataset or GitHub found). items.jsonl therefore holds only the 8 illustrative examples (one per category) from the public page. They are not a random sample: they are likely
  simple, representative-by-design examples, so time estimates from them may be biased low. No uniform draw was possible.
- Grading method: `exact_answer` (deterministic checks vs fixed reference: classification term match, structured field/amount comparison, numerical with tolerance 0.5% relative, MCQ). No LLM judge. Pass = case score >= 0.8 (MCQ binary).
- Description for time estimators: A short bookkeeping request in an accounting system with a chart of accounts, e.g. classify a bank transaction to an account, write a journal entry, record a vendor bill or customer invoice, reconcile a bank balance, compute a figure from given numbers, or adjust an allowance; done when the account, debit/credit direction and amounts match the reference.
- Published human times: none.
- scores.csv: 38 rows in two incomparable rounds. (a) Oct 2026 v1.0 (eval release 2026-10-13): 23 models, release dates 2026-07-08 to 2026-11-09; accuracy = share of the 101 cases passed in at least 2 of 3 runs (not plain pass@1; per-run accuracy is not published; "consistency" = passed all 3 runs is on the page for the top ~10 models only).
  (b) March 2026 round: 15 of 19 models (top-10 plus bottom-5 as printed in the GPT-5.4 blog), release dates 2023-03 to 2026-03, binary grading, runs aggregation not stated. The page says results from different versions should not be combined; use Oct 2026 for the main fit, March as a cross-check only (e.g. Claude Opus 4.6 38.6% is oddly low vs Sonnet 4.6 63.4%, and Claude Fable 5.2 81.2% appears in a late-updated post).
- Problems: vendor benchmark by an ERP seller; no item access; scores clustered near ceiling (78-91%) in the newest round; release dates from vals.ai/Mercor model pages (a few differ by days between sources); three older release dates from memory (flagged); Qwen3 Coder Next and Nemotron Nano 12B dates blank;
  eval date for Oct round = 2026-10-13 release stamp, March round only month. Next-best public substitute: APEX-Accounting dev set (10 tasks) or Vals Finance Agent public set for item texts.
