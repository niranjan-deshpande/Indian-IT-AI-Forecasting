# vals_finance_agent (Vals AI Finance Agent) - source notes

- Accessed 2026-11-10. Data: https://raw.githubusercontent.com/vals-ai/finance-agent/main/data/public.csv (50 rows) and .../finance-agent-v2/main/data/public.csv (27 rows) (raw/*.csv); no licence file checked, treat as research use with citation (commit not recorded: fetched from main).
  Leaderboards (raw/*.html): https://www.vals.ai/benchmarks/finance_agent (v1.1, updated 2026-06-04, 51 models), .../finance_agent_v1 (v1 archived, updated 2026-02-10, 59 models), .../fabv2-1 (v2.1, updated 2026-11-09, 39 models).
  Release dates from each model's vals.ai/models/<slug> page (raw/models/).
- Population: the headline accuracy is on the PRIVATE Test set (337 questions for v1/v1.1; 449 for v2.1). Public sets are 50 (v1) and 27 (v2) open validation samples, and a private 150 (v1) / 450 (v2) validation set exists.
  items.jsonl = random.Random(2026).sample(sorted(str(row index 0-49)), 24) from the 50 v1 public rows (split preserves question-type mix per Vals). items_v2.jsonl (extra) = all 27 v2 public items, unsampled.
  Public rows are a sample of the same distribution as the test set per Vals, not the test items themselves. Item ids = 0-based row index in public.csv (lexicographic sort).
- Grading method: `llm_judge` (LLM judge/jury checks the final answer against an expert rubric; v2.1 uses a 3-model jury). Answers must be single committed values; hedged answers fail in v2.1.
- Description for time estimators: A financial-analyst research question about a public company, to be answered from SEC filings (10-K, 10-Q, earnings releases) and web search plus a calculator, e.g. find a repurchase count and compute a percent change, compare two retailers' inventory days, or judge an earnings beat; done when the answer matches the expert's answer and rubric.
- Published human times: yes. Column `Expert time (mins)` in both public CSVs, "time an expert took to answer" (Vals; measurement protocol not described on the pages). v1 public: median 10 min, range 2-60 (sampled 24: median 12.5); v2 public: median 40, range 15-120. Field kept in meta.expert_time_mins.
- scores.csv: v1.1 (51) + v1 (59) rows, `[FA v1.1]`/`[FA v1]` suffix, same model can appear in both with different scores (different version; v1.1 fixed data); release dates 2024-07-18 to 2026-04-30. Fit on v1.1 where available, use v1 rows only for older models.
  scores_v2_1.csv (extra): 39 models, 2026-05-31 to 2026-11-09, on v2.1 (harder questions; items_v2 is its public sample, expert median 40 min). Scores are not comparable across v1.x and v2.x. Thinking and non-thinking variants are separate rows (Vals lists them separately), best-of is not collapsed.
- Problems: items are the 50-row public subset, not test items; eval date per model not shown (page update date used); model names include post-training-cutoff models and could not be cross-checked against provider announcements; Gemma/Jamba and one Mistral model have a blank or unverified release date
  (Jamba 1.7 Large, mistralai/magistral-medium-2506 not linked); v1 saturation noted by Vals (v1 archived); v1 durations of 45.20s are placeholder-like values for older runs; harness is Vals's open-source agent with fixed tools, same for all models.
