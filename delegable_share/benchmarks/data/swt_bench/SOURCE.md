- Grading method: `tests`. Generated tests are run before and after the gold patch; success = fail-to-pass (S). Coverage delta is a secondary metric (not used).
- Description for time estimators: Given a bug report and the code repository before the fix, write automated tests in the project's test suite that fail on the buggy code and would pass once the bug is fixed; the fix itself is not required.
- Published human times: none for tests. SWE-bench Verified `difficulty` (annotator estimate of time to FIX the issue: <15 min, 15m-1h, 1-4h, >4h) is the only proxy; upper bound for test writing.
